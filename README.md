# takotubo-museum

VRChat ワールド「DX たこつぼ」の美術館で飾る絵の配信用リポジトリです（GitHub Pages）。ワールドから VRCImageDownloader で読み込むためのもので、一般向けのギャラリーではありません。

This repository hosts images for the museum in the VRChat world "DX Takotubo", served via GitHub Pages and loaded in-world with VRCImageDownloader.

- `pc/<exhibition>/<id>.jpg` : long edge up to 2048 px, JPEG q88
- `quest/<exhibition>/<id>.jpg` : long edge up to 1024 px, JPEG q85
